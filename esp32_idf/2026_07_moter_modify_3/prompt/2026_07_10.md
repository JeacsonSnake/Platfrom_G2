## 项目环境
- **SoC**: ESP32-S3
- **SDK**: ESP-IDF（VSCode 扩展编译，非 Arduino）
- **电机**: 驰海电机 CHB-BLDC2418（永磁直流无刷电机，内置驱动板）
- **控制接口**:
  - PWM 调速（蓝色线）：反相逻辑，13-bit LEDC，**Duty 8191 = 电机 OFF**，Duty 0 = 电机 ON
  - 方向控制（黄色线）：CW/CCW
  - 转速反馈 FG（绿色线）：**每转 6 脉冲 (6 PPR)**，5V 方波
- **额定参数**:
  - 使用电压: DC 24.0V
  - 空载转速: **9000 ± 10% RPM**
  - 额定转速: **7750 ± 10% RPM**
  - 空载电流: 0.07 A MAX
  - 额定电流: 0.16 A MAX
  - 堵转电流: 0.43 A
- **采样周期**: PCNT 与 PID 控制周期均为 **200ms**（5Hz）
- **量纲约定**: 代码中 `motor_speed_list[index]` 与 `pcnt_count_list[index] * 5` 均使用 **pulses/sec**（每秒脉冲数）作为速度单位

## 已诊断出的关键问题（必须修复）
请基于以下已知问题，进行最小改动修复：

### 1. 量程错误：`PID_MAX_PCNT` 只设了一半（请确认）
现有代码中：
```c
#define PID_MAX_PCNT (450)   // 错误：对应 4500 RPM
```
但参考新上传的 `hardware_info\motor_parameter_list.jpg`，电机空载转速实际为 **9000 RPM** ，对应 FG 频率：
`9000/60×6=900 pulses/sec`
**修复**：将 `PID_MAX_PCNT` 改为 **900**。所有基于 450 量程的注释、原有的`hardware_info\CHB-BLDC2418-Motor-Configuration.md`信息和逻辑需**同步更新**。
### 2. PID 算法结构错误：位置式与增量式混合（请确认）
现有 `PID_Calculate` 中：
```c
data->integral += error;              // 位置式积分累加
output = data->pre_input + output;  // 增量式输出累加（错误！）
```
这导致 **积分作用被计算了两次**，是振荡和超调的根源。
**修复**：改为**纯位置式** PID。`output` 直接等于 `Pout + Iout + Dout`，**不再与 `pre_input` 相加**。`pre_input` 字段应从 `PID_data` 中移除或不再使用。
### 3. 微分项对设定值突变敏感（Derivative Kick，请确认）
现有代码对 error 做微分：
```c
double derivative = (error - data->pre_error);
```
当目标转速突变时，微分项会产生冲击。
**修复**：改为**微分先行**（Derivative on Measurement），即对 `current_speed` 微分而非对 `error` 微分：
```c
double Dout = params.Kd * (data->pre_current - current_speed);
```
需在 `PID_data` 中增加 `pre_current` 字段（或替换 `pre_input`）。
### 4. PCNT 异常阈值过低（请确认）
现有代码：
```c
const int MAX_REASONABLE_PCNT_PER_200MS = 150;
```
150 pulses/200ms = 750 pulses/sec = 7500 RPM。但空载 9000 RPM 时 200ms 应有 **180 个脉冲**，正常高速会被误判为异常。
**修复**：将阈值改为 **250**（对应 12500 RPM，留足 margin）。异常检测的相对突刺倍数从 `5` 放宽到 `8`。
### 5. 积分限幅逻辑不精确（请确认）
现有代码对 `integral` 的限幅使用 `params.max_pwm`（8191），但积分项乘以 `Ki` 后才加入输出，直接限幅 `8191` 在 `Ki` 很小时过于保守。
**修复**：积分限幅应基于 `params.max_pwm / params.Ki`（或一个合理的最大积分贡献值）。
### 6. 软启动逻辑与 PID 状态重置耦合混乱（请确认）
现有 PID_init 中软启动和状态重置逻辑分散，且 `pre_input` 的残留会影响下一次启动。
**修复**：软启动改为**输出速率限制**（Rate Limiter），即限制每周期 `new_input` 的最大变化量，而非限制绝对输出上限。启动边沿检测时，清零 `integral`、`pre_error`、`pre_current`。

## 调参与验证要求
请在代码注释或文档中提供以下调参指南：
### 手动整定流程（推荐）
1. **开环阶跃测试**：固定输出 50% PWM（即反相后的 duty ≈ 4096），记录 200ms 内的 `pcnt_count` 稳定值，计算电机增益 **K** （pulses/sec per %PWM）和时间常数 **τ**（达到 63% 稳态值的时间）。
2. **纯 P 测试**：设 `Ki=0, Kd=0`，从 `Kp=1.0` 开始，逐步提高直到出现轻微振荡，记录临界增益 **Ku** 和振荡周期 **Tu**。
3. **加入 I**：设 `Ki = Kp / (2 * τ)` 或按 ZN 公式 `Ki = 1.2 * Kp / Tu`，逐步消除静差。
4. **加入 D**：设 `Kd = Kp * Tu / 8` 或从 `0.5` 开始，抑制超调。若高频噪声大，降低 `Kd`。
5. **低速测试**：目标设为 `90 pulses/sec`（约 900 RPM），观察是否平稳。若抖动，降低 `Kd` 或增加 `PCNT` 滤波。
